# Goal

-> agents should run for long runs
     -> tools can run in remote environments
     -> storage and environments are light, sqlite/jsonl, not-node only

Tasks:
- run
    - checkpoint1: step 1 (task)
    - checkpoint2: step 2 (task) -> dies

- recover run, check for unfinished tasks, continues each from last checkpoint

# Conclusion:
- Durable is a way to make sure all state around an agent conversation is preserved,
  including possible documents created. Also multiplayer.

Looks like a framework for what's needed to create assistant apps.

It seems we could use it to create an Amp, for instance.
Or other apps that can embed agents inside it.

Building blocks for building agents that run for long time.
